## 使用约定

1. 素材表先保留原图，切图后将独立资源放到对应子目录。
2. 原型图本身仅作为视觉参考，不直接作为最终页面背景使用。
3. 页面接入顺序：登录页 → 游戏大厅 → 德州扑克桌 → 其他牌桌 → 业务页面。
4. 接入前先确认素材比例、裁切范围、透明边缘和 16:9 横屏适配。
